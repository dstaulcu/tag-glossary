# Facets

Every tag is `<facet>/<name>`. The core defines the facets; teams add values under them. Propose a new facet to the core group.

- `project`: a project or initiative. Usually owned by a team.
- `community`: who benefits from the work.
- `tactic`: a capability or method, named by capability and not by tool.
- `tool`: a product or project name.
